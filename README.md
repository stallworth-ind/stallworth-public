# Stallworth N-Queens

Solve the N-Queens puzzle with a standalone Python example. Browse its source, graph details, test coverage, security checks and solver outcomes.

Prepared locally from a validated candidate. Downloads use local files in a file preview; the planned GitHub release links become available after publication. This record does not confirm a tagged release.

Python 3.12+; runtime uses the standard library. Download the wheel, then run:

```sh
python -m pip install <downloaded-wheel>
stallworth-nqueens --help
```
